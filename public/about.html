About Host

Host Control Center is a private property-operations workspace used to organize apartment inventory, stock shortages, cleaner reminders, guest Wi-Fi and check-in information, parking guides, invoices, and access-controlled operational data.

Private operations tool Google Sheets read-only integration Firebase authentication

What the application does

Host brings recurring property-management workflows into one authenticated interface so authorized users can work from a consistent source of operational information.

  • Reads stock-tracker information from a Google Spreadsheet when the user explicitly connects Google Sheets.
  • Shows low-stock alerts and helps prepare cleaner reminder messages.
  • Stores apartment operational records, access roles, Wi-Fi details, guest check-in instructions, parking guides, agent information, and Airbnb policy notes in the application's Firebase environment.
  • Creates cleaner invoices and provides guest-facing copy tools for operational messages.

Google Sheets access

The Google Sheets integration requests read-only spreadsheet access. Host uses that permission only after an authorized user chooses to connect Sheets, and only to retrieve spreadsheet structure and values needed for the inventory, alert, and cleaner workflows.

Host does not use the Google Sheets permission to edit, delete, or create spreadsheet content.

Access and audience

Host is not a public consumer service. The operational application requires authentication and an authorized access role. These public pages exist so users and platform reviewers can understand the application, its data practices, and its terms without signing in.
